# 🏦 SecureBanking-System-Python-MySQL

A command-line **Bank Management System** built using **Python (Object-Oriented Programming)** and **MySQL**.
This project simulates basic banking operations such as account creation, deposits, withdrawals, balance inquiries, and secure PIN management through a terminal interface.

The goal of this project is to demonstrate the practical implementation of **OOP concepts**, **database integration**, and **secure transaction handling** using Python.

---

## 📌 Project Description

SecureBanking-System-Python-MySQL is a simple banking application that allows users to perform common banking operations through a command-line interface. The system stores customer and transaction data in a MySQL database and ensures secure access using PIN verification.

This project showcases:

* 🧠 Object-Oriented Programming concepts
* 🔗 Database connectivity using Python
* 💳 Transaction management
* 🔐 Basic security through PIN authentication

---

## ✨ Features

* 🆕 Create a new bank account
* 💰 Deposit money into an account
* 💸 Withdraw money from an account
* 📊 Check account balance
* 🔑 Update account PIN securely
* 📜 View transaction details
* 🗄️ MySQL database integration

## 🚀 How to Run the Project

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/kunamalla-Tharun7/SecureBanking-System-Python-MySQL.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd SecureBanking-System-Python-MySQL
```

### 3️⃣ Install Required Packages

```bash
pip install mysql-connector-python
```

### 4️⃣ Setup MySQL Database

Create a database in MySQL:

```sql
CREATE DATABASE bank_db;
```

Update your database credentials in the Python file:

```python
host="localhost"
user="your_username"
password="your_password"
database="bank_db"
```

### 5️⃣ Run the Application

```bash
python main.py
```
